Easypost Odoo Connector
=======================
Integrates your Easypost Shipping from Odoo.

Configuration
=============
* First you need to install the easypost python package (pip install easypost)
then create the Easypost API Key.
1) Go to https://www.easypost.com/ and login to your account.
2) Click on Account Settings.
3) Under API Keys tab, you can see the API Key.
